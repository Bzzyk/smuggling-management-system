# Mapa wymagan punktowanych

Ten dokument wskazuje wymagania, ktore sa spelnione albo mozliwe do obrony
na podstawie aktualnego kodu projektu, wraz z konkretnymi miejscami implementacji.

## Wymagania ogolne

| Wymaganie                         | Przyklad miejsca w projekcie                                                                                                                                                                                                                                                                                                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Co najmniej 3 klasy domeny        | Encje w `backend/src/main/java/pl/edu/pb/smuggling/**/model`, np. `user/model/User.java`, `order/model/SmugglingOrder.java`, `transport/model/Transport.java`, `transport/model/Route.java`, `transport/model/Vehicle.java`, `cargo/model/Cargo.java`, `payment/model/Payment.java`.                                                                                            |
| Relacje pomiedzy klasami domeny   | `order/model/SmugglingOrder.java` ma relacje do `User` i `OrderStatus`; `transport/model/Transport.java` ma relacje do `SmugglingOrder`, `Route`, `Vehicle`, `TransportStatus`; `transport/model/SmugglerAssignment.java` laczy transport z profilem przemytnika.                                                                                                               |
| Zroznicowane typy pol, w tym data | `transport/model/Transport.java` zawiera `Integer`, `String`, `LocalDate`, `LocalDateTime`; `order/model/SmugglingOrder.java` zawiera `String`, `BigDecimal`, `LocalDate`, `LocalDateTime`; `vehicle/model/Vehicle.java` zawiera `String`, `Integer`, `Boolean`, enum `VehicleType`.                                                                                            |
| Ograniczenia wartosci pol         | DTO formularzy, np. `transport/dto/RouteFormDto.java`, `transport/dto/VehicleFormDto.java`, `transport/dto/TransportFormDto.java`, `cargo/dto/CargoFormDto.java`, `user/model/dto/UserCreateRequest.java`, zawieraja `@NotBlank`, `@NotNull`, `@Size`, `@Min`, `@DecimalMin`, `@Email`.                                                                                         |
| Logowanie i role uzytkownikow     | `config/SecurityConfig.java`, `user/service/CustomUserDetailsService.java`, encje `user/model/User.java`, `user/model/Role.java`, kontrola metod przez `@PreAuthorize` w kontrolerach. Role slownikowe sa seedowane w `database/02_dictionaries.sql` i `seed/SampleDataSeeder.java`.                                                                                            |
| Interfejs Thymeleaf               | Widoki w `backend/src/main/resources/templates`, np. `templates/transports/list.html`, `templates/orders/form.html`, `templates/users/list.html`, `templates/fragments/layout.html`.                                                                                                                                                                                            |
| CRUD w MVC                        | Kontrolery MVC: `order/controller/OrderController.java`, `transport/controller/TransportController.java`, `transport/controller/RouteController.java`, `transport/controller/VehicleController.java`, `cargo/controller/CargoController.java`, `cargo/controller/WarehouseController.java`, `payment/controller/PaymentController.java`, `user/controller/UserController.java`. |
| CRUD w REST                       | Kontrolery REST: `user/controller/UserRestController.java`, `order/controller/OrderRestController.java`, `transport/controller/rest/TransportRestController.java`, `transport/controller/rest/RouteRestController.java`, `transport/controller/rest/VehicleRestController.java`. Szczegoly endpointow sa w `docs/08-api-rest.md`.                                               |

## Szczegolowe funkcjonalnosci

| Wymaganie                                                               | Przyklad miejsca w projekcie                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dodanie, edycja, usuniecie/dezaktywacja, wyswietlanie danych domenowych | MVC: `RouteController.java`, `VehicleController.java`, `CargoController.java`, `WarehouseController.java`, `PaymentController.java`, `UserController.java`; REST: `RouteRestController.java`, `VehicleRestController.java`, `TransportRestController.java`, `UserRestController.java`, `OrderRestController.java`.                                                     |
| Walidacja formularza, co najmniej 6 regul                               | `VehicleFormDto.java` (`@NotBlank`, `@Size`, `@NotNull`, `@Min`), `CargoFormDto.java` (`@DecimalMin`), `UserCreateRequest.java` (`@Email`), `TransportFormDto.java` (`@DateTimeFormat` + wymagane pola). Uzycie walidacji przez `@Valid` jest w kontrolerach, np. `TransportController.java`, `RouteController.java`, `VehicleController.java`, `UserController.java`. |
| Edycja na danych biezacych                                              | Formularze edycji wypelniaja DTO aktualnymi danymi encji, np. `TransportController.showEditForm(...)`, `OrderController.showEditForm(...)`, `UserController.editUserForm(...)`, `RouteController.showEditForm(...)`, `VehicleController.showEditForm(...)`.                                                                                                            |
| Wspoldzielenie danych miedzy uzytkownikami z rolami                     | Modul transportow: `TransportController` pozwala `ADMIN/BOSS` przypisac przemytnika do transportu; `TransportAssignmentService` wykonuje przypisanie; `TransportService.getVisibleTransports(...)` i `TransportRepository.findVisibleTransports(...)` ograniczaja widocznosc. `SMUGGLER` widzi tylko transporty przypisane przez `SmugglerAssignment`.                 |
| Sortowanie w obu kierunkach, co najmniej 3 kryteria                     | Lista transportow: `templates/transports/list.html` ma selecty `sort` i `dir` oraz linki sortowania; `TransportController.listTransports(...)` przekazuje kryteria; `TransportService.getTransportSortProperty(...)` dopuszcza `transportDate`, `startLocation`, `destination`.                                                                                        |
| Zapamietanie kierunkow i kryteriow sortowania                           | `TransportController.listTransports(...)` uzywa `HttpSession` i atrybutow `transportSort`, `transportDir`, `transportStatus`, `transportDateFilter`; helper `resolveSessionValue(...)` odtwarza wartosci z sesji, gdy request ich nie podaje.                                                                                                                          |
| Filtrowanie wedlug daty od aktualnej                                    | `templates/transports/list.html` zawiera select `dateFilter` z opcja `FUTURE` / "Od dzisiaj"; `TransportService.getDateRange(...)` liczy zakres od `LocalDate.now()`; `TransportRepository.findVisibleTransports(...)` filtruje `t.transportDate >= :dateFrom`.                                                                                                        |
| Filtrowanie po polu domenowym sortowanym od najpopularniejszej wartosci | Pole domenowe: status transportu. `TransportRepository.findStatusPopularity()` zlicza `COUNT(t)` po `t.status.name` i sortuje `ORDER BY COUNT(t) DESC`; `TransportService.getStatusPopularity()` przekazuje dane; `templates/transports/list.html` wyswietla statusy z liczba wystapien.                                                                               |
| Logowanie                                                               | `SecurityConfig.java` konfiguruje `formLogin(...)`, `templates/login.html` zawiera formularz logowania, `CustomUserDetailsService.java` laduje uzytkownika z bazy.                                                                                                                                                                                                     |

## Elementy techniczne

| Wymaganie                                           | Przyklad miejsca w projekcie                                                                                                                                                                                                                                                                 |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kontrolery                                          | MVC i REST w pakietach `controller`, np. `OrderController.java`, `TransportController.java`, `RouteRestController.java`, `TransportRestController.java`, `UserRestController.java`.                                                                                                          |
| Baza danych, co najmniej 2 tabele z relacja         | Schemat w `database/01_schema.sql`, np. `orders` -> `users`, `transports` -> `orders/routes/vehicles/statuses`, `smuggler_assignments` -> `transports/smuggler_profiles`. Encje JPA odzwierciedlaja te relacje w katalogach `model`.                                                         |
| Widoki, formularze z walidacja, znaczniki Thymeleaf | Widoki w `templates`, np. `templates/transports/form.html`, `templates/routes/form.html`, `templates/users/form.html`. Uzywane znaczniki/atrybuty Thymeleaf: `th:action`, `th:object`, `th:field`, `th:each`, `th:if`, `th:text`, `th:href`, `th:selected`, `th:errors`.                     |
| Sesja                                               | `SecurityConfig.java` konfiguruje sesje i `SessionRegistry`; `UserService.changePassword(...)` wygasza aktywne sesje uzytkownika; `TransportController.listTransports(...)` bezposrednio uzywa `HttpSession` do zapamietywania filtrow i sortowania transportow.                             |
| Usluga REST                                         | REST API w `UserRestController.java`, `OrderRestController.java`, `TransportRestController.java`, `RouteRestController.java`, `VehicleRestController.java`, `AuditLogRestController.java`, `AuthLogRestController.java`. Dokumentacja: `docs/08-api-rest.md`, Swagger: `OpenApiConfig.java`. |
| Spring Security z baza danych                       | `SecurityConfig.java`, `CustomUserDetailsService.java`, `UserRepository.java`, encje `User.java` i `Role.java`, tabele `users`, `roles`, `user_roles` w `database/01_schema.sql`. Hasla kodowane przez `BCryptPasswordEncoder`.                                                              |

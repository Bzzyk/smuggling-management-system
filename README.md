# Smuggling Management System

Projekt edukacyjny realizowany na potrzeby przedmiotów:

- Systemy baz danych
- Projektowanie aplikacji WWW w języku Java

## Temat projektu

System zarządzania przemytem papierosów.

Projekt ma charakter fikcyjny i edukacyjny. Celem projektu jest zaprezentowanie mechanizmów projektowania relacyjnej bazy danych oraz aplikacji webowej w Javie.

## Technologie

- Java
- Spring Boot
- Spring Security
- Spring Data JPA / Hibernate
- Thymeleaf
- PostgreSQL
- Swagger UI
- REST API
- Bootstrap
- Git / GitHub

## Główne moduły systemu

- użytkownicy i role
- zlecenia
- transporty
- trasy
- pojazdy
- kurierzy
- ładunki
- magazyny
- płatności
- raporty
- audyt zmian
